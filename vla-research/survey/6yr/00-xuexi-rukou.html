1. 五分钟速览：10 个问题

  1. VLA 和 VLM 的区别是什么？ VLM 输出文本，VLA 输出动作。动作可以是离散 token（RT-2）、连续向量（OpenVLA）或动作块（ACT）。详见 01 §1。
  2. 为什么动作要离散成 token？ 为了复用 VLM 词表和自回归解码。RT-1 用 256 bins，RT-2 直接生成文本 token，G0.5 用 RVQ 把 27 维动作压成 token。
  3. 为什么 2026 年又回到 flow matching？ 连续高频控制需要平滑动作序列。DiT4DiT、DM0.5、PRTS 用扩散/flow 动作头；离散 token 仍适合语义推理。详见 01 §1。
  4. 3DGS 进策略网络了吗？ 没有。现有材料里 3DGS 主要做数据引擎、场景表示、世界模型；最接近的是 GaussianWAM 的“训练期教师、推理不渲染”。详见 01 §4。
  5. RVQ 作为第四条动作路线解决什么？ 把异构动作压到共享离散空间，再多轮精修。G0.5 的 ActionCodec 是代表；FAST 的 DCT+BPE 是另一条 tokenizer 路线。详见 01 §1。
  6. 0.5B 能替代 3B 吗？ 单任务精调可能够；跨本体泛化仍需要大模型。Evo-1 0.77B 在多个基准接近 3B，EffVLA 的效率膝约 3.75B。详见 01 §5。
  7. 世界模型和 VLA 是什么关系？ World-Action Model 联合预测未来与动作；Efficient-WAM/Light-WAM 把“想象未来”压到 1B 级，3DGS 世界模型是另一条线。详见 01 §6。
  8. harness 为什么不改模型也能涨点？ 冻结策略，把智能放到编排、记忆和解析原语里。Harness VLA 在 LIBERO 上 84.2% 的调用是解析原语，vla_act 只占 15.8%。详见 01 §7。
  9. LIBERO/RoboTwin/RoboDojo 的分数能横比吗？ 不能。子套件、rollout 数、no-noops、Easy/Hard、仿真/真机都不同；引用时必须带基准名。详见 02 §4–§5。
  10. 2026 年还有哪些空位？ 3DGS-native 轻量 VLA、RVQ-head 的其他工作、TurboVLA、闭环量化、WAM 成本曲线、harness 可验证性、RoboDojo 排名。详见 03 §4。

2. 概念入门

概念一句话本目录里的例子
VLA视觉 + 语言输入，输出机器人动作RT-2、OpenVLA
动作头把模型表征变成动作的最后一层256 bins、7 维连续、flow matching、RVQ
action chunk一次预测并执行多步动作ACT 的 chunk size 10
VLM backbone视觉语言模型主干PaLI-X、LLaMA-2、Qwen3.5、Gemma3
数据/基准训练数据与评测协议OXE、LIBERO、RoboTwin 2.0、RoboDojo
harness策略之外的编排层Harness VLA、Agentic-VLA、EVA-Client

一张最小的心智图：

图像 + 语言 + 本体状态
        ↓
VLM backbone（视觉塔 + 语言模型）
        ↓
动作头（离散 token / flow / RVQ / 回归）
        ↓
动作块 → 机器人

先记住这条链路，后面所有模型都可以放进来：换 backbone、换动作头、换数据、换评测、加 harness。

4. 必读 10 篇

4.1 RT-2（2023，Google DeepMind）

  • 一句话：把动作当文本 token，让 VLM 的互联网知识迁移到机器人。
  • 机制：PaLI-X/PaLM-E + 机器人数据与 VQA 联合微调。
  • 数字：55B 参数，推理低于 1Hz；章节未给成功率。
  • 开源：章节未说明。
  • 深入：本地 RT 系列导读；01 §1–§2。

4.2 OpenVLA

  • 一句话：开源 7B 级 VLA，把 VLM 权重和 7 维连续动作接起来。
  • 机制：SigLIP/DINOv2 + LLaMA-2/Vicuna/Mistral，MLP projector，7 维连续动作。
  • 数字：章节未给成功率；约 10.3GB 显存。
  • 开源：openvla/openvla、openvla/openvla-7b。
  • 深入：本地 OpenVLA 导读；01 §2。

4.3 ACT

  • 一句话：小数据、小模型的动作块策略，是理解 VLA 动作头的最低门槛。
  • 机制：ResNet18 + CVAE + Transformer，一次预测 10 步动作。
  • 数字：51.55M 参数；单卡 30–60 分钟；建议 20–50 条轨迹。
  • 开源：LeRobot 生态，代码公开。
  • 深入：本地 ACT 导读；03 §2。

4.4 DiT4DiT

  • 一句话：把视频生成 backbone 接到扩散动作头，代表“大 backbone + 小可训练头”路线。
  • 机制：Cosmos-Predict2.5-2B + 扩散动作头，只训 1.53% 参数。
  • 数字：总参数 10.64B；LIBERO spatial 10/10 只是 smoke test。
  • 开源：mondo-robotics/dit4dit-model；Cosmos backbone 为 gated。
  • 深入：本地 DiT4DiT 导读；01 §1。

4.5 Galaxea G0.5

  • 一句话：把 reasoning token 和 action token 放进同一条自回归流。
  • 机制：Qwen3.5 2B + 27 维 ActionCodec（RVQ）+ 短期视觉记忆。
  • 数字：DROID 82.5%、Bridge 87.3%、RoboTwin 93.3%、LIBERO 98.9%。
  • 开源：OpenGalaxea/GalaxeaVLA；权重 gated，非商业许可。
  • 深入：本地 G0.5 导读；01 §1。

4.6 PRTS

  • 一句话：把 contrastive RL 放进 VLA 预训练，强调目标可达性。
  • 机制：Qwen3-VL-4B + flow matching action expert + contrastive RL。
  • 数字：LIBERO 四套平均 98.4；约 167B tokens、64 张 H100。
  • 开源：TeleHuman/PRTS、TeleEmbodied/PRTS-4B；CC BY-NC 4.0。
  • 深入：本地 PRTS 导读；01 §3。

4.7 Agentic-VLA

  • 一句话：在 OpenVLA-OFT 外增加在线适应外环，用经验记忆和奖励合成加速新任务。
  • 机制：Experience Memory + Language-Guided Exploration + Adaptive Reward Synthesis + GRPO。
  • 数字：LIBERO 平均 97.8；RoboTwin Easy 62.5% / Hard 34.7%。
  • 开源：无官方 GitHub 仓库。
  • 深入：本地 Agentic-VLA 导读；01 §7。

4.8 Harness VLA

  • 一句话：冻结 VLA，把智能放到运行时编排、记忆与解析原语里。
  • 机制：vla_act + 6 个解析原语 + TSM/GM 双记忆。
  • 数字：LIBERO-Pro 82.4%、RoboCasa 57.2%、C2R 58.4%；84.2% 调用是解析原语。
  • 开源：RLinf/RPent。
  • 深入：01 §7；02 的 Harness 来源。

4.9 DM0.5 / OpenDM

  • 一句话：Dexmal 的 6B 级 VLA，重点在推理延迟与部署栈。
  • 机制：Gemma3 VLM prefix + Action Expert suffix + Flow Matching。
  • 数字：官方公告 4090D 核心延迟 534.04→57.49ms（9.29×）；LIBERO 98.45%→98.40%。
  • 开源：dexmal/opendm Apache-2.0；9.29× 部署栈未完整公开。
  • 深入：本地 DM0.5 导读；01 §5。

4.10 VisualThink-VLA

  • 一句话：用四类视觉证据替代长文本 CoT，降低闭环控制延迟。
  • 机制：bbox/edge/motion/relation 四类证据 + 冻结 VLA backbone。
  • 数字：BridgeData V2 89.49%；相对 ECoT 约 22.8× 加速。
  • 开源：DCDmllm/VisualThink-VLA 代码骨架；权重/数据未包含。
  • 深入：本地 VisualThink-VLA 导读；01 §1。
