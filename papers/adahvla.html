特点时间线上最纯粹的"harness 依据执行证据自适应修订"

① 动机

  • VLA 局部控制与指令遵循强，但长程任务需要持久记忆与规划；任务 harness 恰好提供持久上下文（保留历史、跟踪阶段进度）。
  • 两者互补 → 问题变成：怎么可靠地改 harness？直接改容易噪声化、任务特化。

② 架构：解耦适配 + 修订图

  • 可编辑协调代码：保留任务进度、调整传给局部执行器的指令与上下文；
  • 解耦式多 agent 适配：证据分析、harness 修订、行为评估在不同工作上下文中进行（防自我确认偏误）；
  • 可检验的协调假设：每次修订绑定一个假设，后续 rollout 检验其预测效果；
  • 有状态修订图：节点 = 执行证据 / 假设 / 修订 / 观测到的效果；保留备选 harness 与适应记忆——反复尝试中指导精炼，跨任务跨环境持续适应。

③ 数据与结果

评测数字
NaVILA-LH（长程导航，仿真）平均 22.5% → 最高 57.5%
操纵测试（三个 VLA backbone）较初始 harness 最高 +30.8pp
真机四足机器人多阶段导航稳定执行的定性演示

④ 信息流

执行 → 证据（轨迹/成功位/失败位）
  → 证据分析 agent：提出可检验的协调假设
  → 修订 agent：改协调代码（存入修订图，保留旧版）
  → 行为评估 agent：rollout 验证假设预测
  → 修订图更新：证据-假设-修订-效果连线 → 下一轮或跨任务复用

⑤ 例子

四足机器人按多阶段导航指令行动：完成一段移动却没到下一个预定地点（阶段计数错）→ 修订图记录证据"阶段 2 未到达即推进阶段 3" → 假设"推进前必须校验目标在视野内" → 修订协调代码加入视野校验 → rollout 验证后采纳；真机演示中机器人接近目标 2 偏离后获得纠正指引，到达后继续执行。

⑥ 局限

  • 修订的是代码协调策略，动作层能力上限仍由 VLA 决定；
  • 修订图与多 agent 适配带来额外计算；假设空间受提示设计限制；
  • 真机部分为定性演示而非系统化成功率。

⑦ 簇内定位

  • 与 SERA（自进化 harness 的先行者）：SERA 用 rollout 提/评 harness 修订版本，AdaHVLA 加了显式修订图与假设检验——把"harness 也当作有版本的软件"贯彻到底；
  • 与 HarnessBank：同一问题（怎么可信地改 harness），AdaHVLA 面向机器人、用假设-验证替代统计门控；
  • 与 EmbodiedSkills：EmbodiedSkills 的 runtime 固定、证明验证值 38pp；AdaHVLA 让 runtime 本身可进化——两者可叠加。
