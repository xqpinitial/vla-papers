项内容
一句话把 VLM 的高层决策与运动执行解耦的评测框架：冻结现成 VLM 每 0.5s 发原子全身技能指令，DiT 运动基座 + 每技能 ControlNet 落地成连续动作，Half-Physics 仿真保留重力/碰撞但排除失衡/电机误差——9 个前沿 VLM 最好成绩仅 16.8%
冻结全部被测 VLM（决策者）；运动基座 DiT + ControlNet（执行器，固定）
演化无——这是评测 harness，测的是 action intelligence
基准HumanCLAW-Bench：1,218 个 find-navigate-interact 长程第一人称回合，41 个 HSSD 室内场景

① 动机：失败归因难题

  • 具身任务失败时，分不清是 VLM 决策错了还是运动控制没执行好（比如失衡摔倒）。
  • 两个极端都有缺陷：code agent 抽掉身体（脚本执行无物理后果）；端到端 VLA 把推理和具身控制纠缠在一起。
  • 目标：隔离并测量 action intelligence——在物理环境里逐步闭环做空间决策的能力。

② 架构：三重解耦

模块职责
VLM skill harness渐进式推理脚手架：自我中心感知 → 空间理解 → 动态中级目标（2–3s）→ 原子技能+参数（walk(x,z,ψ)、sit_in_place(h)…）；0.5s 一步
Verifier短上下文 spatial-action outcome QA；accept / reject / renew，拦下不安全或物理不可能的提案
DiT 运动生成技能无关的运动基座 DiT（5 历史姿态 → 15 未来帧 continuation）+ 每技能即插即用 ControlNet 适配器 → 百自由度连续全身运动
Half-Physics 仿真基于 AI Habitat + Bullet：保留重力、碰撞、物体位移等物理后果；用等价运动学速度驱动身体，排除失衡与电机跟踪误差 → 失败必然是决策失败

③ 数据与结果

  • HumanCLAW-Bench：1,218 长程回合（6 类目标家具/物体），分 navigation 子集与 sit 子集；渐进成功指标 FindSR / NavSR / InteractSR。
  • 9 个前沿 VLM 全军覆没：最佳 16.8%；同一 VLM FindSR 可达 75%+ 而 InteractSR 普遍个位数。

④ 核心发现（六条 findings 的精华）

  1. 感知不是瓶颈：目标进视野后识别几乎全对，崩在"看见之后"；
  2. 缺乏具身自我意识（embodied self-awareness）："机器幽灵"效应——能流利描述周围场景，却不知道自己身体在哪：判断不到"已到达"、空间幻觉、肢体撞翻家具无察觉、"向空气里坐下"（不追踪骨盆与座椅的相对位置）；
  3. 推理脚手架至关重要：去掉技能 verifier 导航成功率骤降；增加历史图像帧数反而可能掉点——紧凑文本历史 + 中级目标推理最有效。

⑤ 信息流

高层指令 + 技能注册表 → VLM harness（0.5s 步）
  ← 自我中心 RGB + 文本/结构化记忆
  → 原子技能提案 → verifier 校验（reject 则重提案）
  → DiT + skill ControlNet → 全身 motion chunk
  → Half-Physics 执行（重力/碰撞生效）→ 新 ego 帧 → 循环

⑥ 局限与边界

  • Half-Physics 刻意抽掉运动控制难度——结论只覆盖决策智能，不能外推到全身动力控制；
  • sit 子集与室内场景设定较窄；HSSD-Hab val 资源需授权；
  • 与同名 VisionClaw（可穿戴 always-on agent）无关。

⑦ 簇内定位

  • 时间线里唯一的纯评测侧 harness（另一篇 HarnessEval-W 评世界模型）——共同命题：harness 不只用来提升能力，也用来让"能力"可被可信地测量；
  • 它给整条 harness 路线提供了诊断学基础：为什么"冻结大模型 + 外壳"会有效/无效——因为瓶颈在决策层的具身自我意识，harness 的 verifier/记忆/脚手架恰好在补这一层；
  • 与 EmbodiedSkills 的 verifier、CaP-X 的脚手架发现互相印证：验证与紧凑上下文比堆历史帧更值钱。
