① 动机：智能可以跨域迁移

  • 人类能无缝适应物理与数字世界——数字-真实鸿沟存在于本体/环境/任务，但人类智能本身可迁移。
  • 追问：VLM 的智能能否同样从数字世界泛化到物理控制？RoboDawn 的答案：瓶颈不在从头学具身智能，而在接口 + 在线课（few-shot 演示 grounding 接口用法与解题策略）。

② 架构：命令接口 + 闭环 + ICL

组件设计
语义命令语法离散 translate / rotate / gripper + home/wait/done；步长有界（≤20cm / 90°）；以 GIP（Gripper Interaction Point，双指尖中点）统一标注、状态与命令参考
固定上下文环境/相机 profile E + 命令 primer D_prim + 任务演示 D_task（0/1/N 条）
每轮闭环Observe（多视角标注+状态+grid）→ Reason（进度/计划/scratchpad）→ Act（语义命令 batch）→ Execute（规划→运动→反馈 F_t）→ Adapt（更新 memory M_t）
ICL 构造专家轨迹先降为 waypoints，再转写为命令序列；VLM 为每轮补 rationale——接口用法与任务策略一起进上下文

⑤ 例子

叠块任务 1-shot：演示把"抓块→移到目标上方→放下"降为 5 条 GIP 命令 + 每步 rationale；VLM 在新随机化场景里按相同语法发命令，偏差时用 Adapt 步修正下一步（如"GIP 偏左 2cm，下轮 move 右移 2cm"）。

⑥ 局限

  • 离散小步长命令 → 推理轮数多、长程任务时延高；
  • 依赖 VLM 的空间 grounding 质量（与 HumanCLAW 发现的"自我意识缺失"同源风险）；
  • C2R 设定的"有界随机化"仍在分布邻域内，开放世界未证。
