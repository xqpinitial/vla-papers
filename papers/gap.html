场景FA（固定自动化）与 GR（通才 VLA）之间的中间带：Variational Automation

① 动机：FA 与 GR 之间缺一个范式

  • 固定自动化（FA）可靠但不适配几何/位姿变化；通才机器人（GR）的 model-free VLA 泛化强但不够可靠——商业/工业要求持久、可靠执行。
  • 目标场景：VA 任务——物体几何与位姿有界但明显变化（比 FA 大、比开放世界小）。这是工业现实里最普遍的类别，此前没有系统化学习范式。

② 架构：Graph-as-Policy + 多 agent 合成

  • 策略表示：有向计算图 G=(V,E)——原子技能节点（感知/抓取规划/运动规划/2D-3D 视觉/ROS 翻译/验证…）+ 数据边与控制边（含 success/failure 路由与回环）。灵感来自 ROS 计算图与 TAMP 层次结构：可解释、模块化、可复用。
  • MORSL（Modular Open Robot Skill Library）：首发 51 项技能，声明图 IO、参数与前置条件；混合 ROS 过程与 GraspGen 等 model-free 原语。
  • 多 agent harness（生成与测试分离）：

1. Orchestration Agent 按语义把自然语言任务切段；

2. Skill Agents 为每段合成局部子图；

3. 静态类型检查后拼成可执行图——限制上下文、抑制 agent"作弊"。

  • 持久执行：仿真里学到的图以 edge 解释器在真机持久运行，仿真与真机同一图。

③ 机制：自学习排练（self-learning rehearsal）

  1. 生成内部仿真环境（NVIDIA Isaac Lab），并行排练不同图的多任务实例；
  2. 注册每个节点的前后状态 + 接触反馈 → 失败定位到具体节点；
  3. agent 编辑图拓扑/参数直至成功率与吞吐进入平台期。
  4. 案例：Make Popcorn 初图 33% → 10 轮仿真排练 94%（sim）/ 90%（real, 18/20）；三阶段修复为抓取改进、搬运调整、放置精修。

④ 数据与基准（8 项开放 VA benchmark）

  • VA-I 杂货履约、VA-II 杂货打包、VA-III 做爆米花、VA-IV USB-C 插线（UR5+指尖力反馈）、VA-V 工业洗箱（双臂）；前六项 Franka + LIBERO 衍生场景（4 仿真 + 4 真机）。
  • 关键结果：大位姿变化列 GaP 0.93–0.99 vs VLA ~0.20；π₀.₅ + GaP staging > 2× 裸 VLA；无图单 agent CaP 0%。

⑤ 信息流（一个排练回合）

自然语言任务 → Orchestration Agent 语义切段
  → Skill Agents 各段合成子图（查 MORSL 声明）→ 类型检查 → 拼图
  → Isaac 并行排练多实例 → 记录节点前后状态/接触 → 定位失败节点
  → agent 改拓扑/参数 → 直到 plateau → 同一张图部署真机持久执行

⑥ 例子

VA-II 杂货打包：图中有"逐件抓取→称重→装箱→封箱"路径，封箱节点带 failure 路由回"重摆物品"节点；交互 demo 里 workflow.json 的每个节点可点开看代码、输入与路由，直到全部打包完成。

⑦ 局限

  • VA 设定要求"有界变化"——开放世界泛化（GR 带）仍需 VLA；GaP 的排练依赖可生成内部仿真环境（需要资产与可重建场景）；
  • 图为任务族定制，换任务族需重新合成 + 排练；
  • 51 技能库覆盖面决定上限，缺的技能要人工或 agent 补进 MORSL。

⑧ 簇内定位

  • 与 CaP-X：同属 Berkeley 系 code-as-policy 谱系，GaP 把"代码"升维成"图"（结构化、可校验、可路由）；
  • 与 RoboFoundry：都把系统当可演化对象，GaP 演化的是单任务族的计算图，RoboFoundry 演化的是跨任务文件系统；
  • 与 RAX：RAX 在真实环境探索，GaP 在自建仿真里排练——用仿真吞吐换真机安全；
  • 工业/商用部署视角下，GaP 是六篇外最贴近"产线可靠性"叙事的工作。
