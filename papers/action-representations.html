VLA 模型 Action 表示方式深度调研

一句话：VLA 里"动作怎么表示"，是决定精度、多模态性、推理延迟和跨本体泛化的头号设计决策。 主流方法可归为两条主轴——离散 token（自回归 / 向量量化）与连续生成式表示（回归 / 扩散 / 流匹配 / 能量模型），二者都在建模同一个条件概率 $P(A_t \mid o_t, l)$，差异只在"如何参数化动作空间"。

你写的词实际含义在本文的位置

1. 摘要（TL;DR）

  • 所有 VLA 都可统一为：视觉/语言编码 → 一串"动作 token / 连续轨迹" → 可执行动作；核心差异在于动作 token 如何构造、如何生成。
  • 离散路线（uniform binning、VQ、FAST）：与 LLM/VLM 架构同构，工程简单、可继承 scaling，但有精度下限（bin floor）&#x548C;自回归延迟。
  • 连续生成式路线（扩散、流匹配、EBM）：保留全精度、天然平滑、善于建模多模态动作分布，代价是训练/部署更复杂、需迭代细化。
  • 动作分块（action chunking） 是几乎必备的工程层：一次前向预测一段未来动作，把推理频率与机器人控制频率解耦（§5.3）。
  • 没有"唯一赢家"：接触密集/高精度/高频任务偏向连续生成式；粗粒度/低频率/强泛化任务离散 token 够用甚至更好（见 §7，以及 2026 年关于"离散也能打"的新证据）。

2. 核心问题：什么是 Action 设置

一个 VLA 通常由三部分组成：

组件作用常见选择
视觉编码器图像 → 特征SigLIP、DINOv2、EfficientNet
语言/融合主干理解指令并与视觉交互LLaMA、PaliGemma、Prismatic 等 VLM
动作头（Action Head）输出可执行动作离散 token 解码 / 扩散头 / 流匹配头 / CVAE / EBM

动作头是整模型里"杠杆比"最高、参数最少、却改变最多运行性质的小组件。 它要回答两个问题：

  1. 动作空间：连续数值（关节角、末端位姿、速度、力矩）还是离散 token？
  2. 生成范式：怎么从多模态输入产生这些动作？

统一数学视角（源自 IEEE Access 2025 VLA Survey 与多篇对比研究）：

$P(A_t \mid o_t, l)$

所有方法都在建模这个条件联合概率，区别只是"参数化的方式"——这是贯穿全文的判据。

3. 分类法（Taxonomy）

3.1 四维切分

维度选项
A. 动作空间离散（tokenized）/ 连续（continuous）
B. 生成范式自回归 AR / 连续回归 / 扩散 / 流匹配 / CVAE / 能量模型 EBM / 混合
C. 时间组织单步预测 / 动作分块（action chunking）
D. Token 语义类型原始动作 / 潜表示 / 目标状态 / 代码 / 可供性(affordance) / 轨迹 / 推理链

3.2 按 Token 语义的八类（"An Action Tokenization Perspective" 综述, arXiv:2507.01925）

  1. Language Description——用自然语言描述动作
  2. Code——用代码（Code-as-Policy / ViLa）表达动作
  3. Affordance——预测可操作区域/部位
  4. Trajectory——预测轨迹点序列
  5. Goal State——用目标图/视频表示期望终态
  6. Latent Representation——用 FSQ / NSVQ / VQ-VAE 学到的潜 token（视觉/动作/目标基）
  7. Raw Action——末端位姿、关节角等低层控制命令（数据稀缺、跨本体差）
  8. Reasoning——CoT/逐步分解的中间推理 token（提升泛化但增加延迟）
趋势：层级架构（上层语言/代码规划 + 中层 affordance/轨迹 token + 底层 raw action 策略）与多 token 类型协同成为主流方向。

4. 方法族详述

4.1 离散动作 Token（Autoregressive / VQ）

#### 4.1.1 Uniform Binning（均匀分箱）

  • 做法：每个动作维度独立量化到固定 bin 数（RT-1/RT-2/OpenVLA 常用 256 档；Gato 用 1024；Q-Transformer 用 256）。连续值 → 整数 token → 复用 LLM 词表。
  • 代表：RT-1（Transformer 逐维预测）、RT-2（动作 bin 直接映射到 LLM 文本词表，实现 web+VLA 联合训练）、OpenVLA（7 维 × 256 bin → Llama 特殊动作 token，自回归生成）、Gato、Q-Transformer（保守 Q-learning 自回归）。
  • 优点：与预训练 LLM/VLM 完全同构，复用训练基础设施、损失函数和 scaling 规律。
  • 缺点：

- 精度下限（bin floor）：bin 宽 = 动作范围 / bin 数；5 rad 关节范围配 256 bin ≈ 20 mrad 分辨率，低于此的任务（接触密集/高精度）会结构性失败。

- bin chatter：接触点相邻 bin 间的小幅振荡，后处理也难完全消除。

- 自回归延迟：逐 token / 逐维生成有延迟下界；高频控制吃力。

- 维度独立分箱忽略跨关节相关性。

#### 4.1.2 Vector Quantization（向量量化，VQ / RVQ）

  • VQ-VAE：编码器把整段动作压成潜向量 → 最近邻查 codebook → 离散 code index；通过 Straight-Through Estimator (STE) 或 Gumbel-Softmax 让梯度穿过不可导的 argmin。
  • RVQ（残差 VQ）：逐级量化残差，coarse-to-fine，用 K 个 codebook 指数级扩充容量而不线性增参。代表 VQ-BeT（用 RVQ 捕获多模态演示数据）。
  • VQ-VLA（ICCV）：专门研究"scaling vector-quantized action tokenizers"，证明动作 tokenizer 质量是一阶变量。
  • KineVLA（2026）：提出 bi-level RVQ-VAE，联合捕捉全局任务上下文与细粒度运动学模式，解决均匀分箱忽略跨关节相关性的问题。
  • 优点：压缩长程动作为紧凑 token 流；codebook 本身可作"动作先验/技能库"；便于 sim2real（token 翻译器）与层级技能抽象。
  • 缺点：codebook 训练不稳定（坍缩/空洞）、粒度与任务对齐难、可解释性差。
注：你写的 vqr 在本语境即指这一族（VQ 系列）；在触觉/力觉综述里 "VQR = VQ-based Reconstruction" 指特征量化重建，属感知侧，不在此列。

#### 4.1.3 FAST / DCT + BPE（频率分词，π₀-FAST）

  • 做法（Pertsch et al., arXiv:2501.09747；集成进 LeRobot）：

1. Normalize：动作块 $(H,D)$ 用分位数归一化到 $[-1,1]$；

2. DCT：每维独立做离散余弦变换（JPEG/MP3 同款压缩）；

3. Quantize：round + 丢弃不显著系数 → 稀疏频率矩阵；

4. Flatten：低频优先展开成一维；

5. BPE：对系数训练 BPE 词表，相对传统分词实现 ~10× 压缩。

  • 特性：把任意 VLM 变成 VLA；自回归预测 FAST token；训练比扩散版 π₀ 快 ~5×，在折衣/清桌等灵巧任务上匹配 π₀ 表现；推理因自回归略慢。提供预训练通用分词器 lerobot/fast-action-tokenizer（基于 100 万+ 真机序列，FAST+）。

#### 4.1.4 离散路线的多模态与"反直觉"新证据

  • 离散头原则上可通过 softmax 表达多模态，但逐维串行解码使联合分布被 awkward 地因子化。
  • 关键反转（2026, arXiv:2610.20429 "When Do Discrete Actions Make Good Continuous Controllers?"）：在架构匹配下，离散参数化（即使最简单的 bin 离散回归 DR）可以媲美甚至超越连续，挑战了"精确控制必须连续"的共识。论文对比了 4 种动作头：CR（连续回归）、CF（连续流）、DR（离散回归）、DF（离散流）。结论：tokenizer 设计是一阶变量，离散性是好接口 + 可计算的精度代价，任务物理决定代价是否可接受。

4.2 连续动作回归（Continuous Regression）

  • 做法：动作头直接回归连续值（MLP / L1 / L2）。代表 OpenVLA-OFT（把基础 OpenVLA 的离散自回归换成并行连续预测 + L1 回归 + action chunk）、经典 BC 基线 CR。
  • 致命缺陷：用 MSE 训练的回归会把多模态动作分布平均掉——"从左边绕还是右边绕都行"被平均成"直直撞上去"。演示数据天然多样，这恰恰是机器人数据常态。
  • 定位：简单、推理快（O(1) 单 pass），适合单策略、低多样性场景。

4.3 扩散（Diffusion Policy）

  • Diffusion Policy（Chi et al., RSS 2023 / IJRR 2024）：把 visuomotor 策略表示为条件去噪扩散过程，迭代 Langevin 去噪生成动作序列；擅长多模态分布、高维动作空间、训练稳定。
  • 代表：Octo（开源通用策略，扩散头）、RDT-1B（清华朱军团队，基于 DiT 改造，12 亿参数，双臂操作，引入"物理可解释统一动作空间"统一多机器人数据，仅需 1–5 演示学新技能，代码/模型/数据全开源）、CogACT（VLM 感知 + 扩散"cognition-to-action"块）、GR00T N1（NVIDIA 双系统：VLM System2 ~10Hz 理解 + 扩散 Transformer System1 ~120Hz 出动作，flow matching 驱动，数据金字塔）、GR-2（视频优先世界模型，3800 万视频片段预训练预测未来帧）。
  • 代价：迭代去噪（10–100 步），推理较慢；但多模态能力是它与回归头拉开差距的核心。

4.4 流匹配（Flow Matching）

  • 本质：扩散的确定性变体（概率流 ODE），学习从噪声到动作的速度场（vector field），用少量 ODE 积分步（π₀ 式 ~10 步）生成连续轨迹。扩散的 score 与流匹配的 velocity 都可视为能量函数的负梯度（见 §4.6）。
  • π₀（Physical Intelligence, arXiv:2410.24164, 2024-10）：

- 主干 PaliGemma 3B（VLM 专家，继承互联网语义）+ Action Expert ~300M（流匹配生成连续关节轨迹）；

- ~50Hz 高频连续控制；action chunking 一次预测 50 步（1 秒）；

- 8 类机器人、~10,000 小时遥操作 + Open X-Embodiment 预训练；开源 openpi（Apache-2.0）。

- 与 RT-2（离散自回归）对比：更平滑、高频、灵巧任务（折衣、插线）更强。

  • π₀.5（2025-04）：强化开放世界泛化（未见房间等）。
  • π₀-FAST：见 §4.1.3（同一实验室同时发 AR 与 flow 两版，说明该权衡仍未收敛）。

4.5 CVAE / 动作分块（ACT）

  • ACT（Zhao et al., 2023, ALOHA）：CVAE + Transformer 一次预测 K 步动作块（chunk）；训练用 L1 重建 + KL 正则；推理采样 latent → 解码整块；Temporal Ensemble（重叠 chunk 指数加权平均）平滑过渡。
  • 优点：确定性单 pass（GPU 上 ~4ms/chunk），快；CVAE 捕获多模态；数据高效（50 演示达人类水平双臂插入/布线）。
  • 定位：专家策略（单任务、少数据），不原生理解语言；与 VLA（跨任务语言泛化）互补。是 Diffusion Policy 之外第二大主流策略架构。

4.6 能量模型（Energy-Based Models, EBM）

  • 统一视角：扩散的 score 与流匹配的 velocity 都是能量函数的负梯度；因此扩散与流匹配策略都可重写为 EBM，为"分布级集成"提供罗塞塔石碑（见 EnsembleVLA）。
  • EBT-Policy（Energy-Based Transformers）：能量参数化策略，2 步收敛 vs Diffusion Policy 100 步（50× 推理提速），66% 更少训练轮次；涌现零样本重试（retry）&#x4E0E;不确定性感知推理（用标量能量动态分配算力）。
  • EqC（Equilibrium Energy Control）：把生成式动作细化视为平衡寻优，用能量一致性信号做 Energy-Gated DAgger——越界时专家接管、收集恢复轨迹再聚合训练；可嵌入 Diffusion Transformer 与流匹配 VLA。
  • TeV（Temporal Verification）：轻量对比式 EBM 验证器，用历史压缩成 temporal token 给流匹配策略"时序锚"，既引导生成又对候选排序，抑制振荡/错误累积（参数增量 < 0.15%）。
  • EnsembleVLA：把多个 VLA（扩散+流）统一为 EBM，加性能量 = 乘概率分布，偏好各模型一致认可的高概率动作；跨范式集成（DP+π₀.5）仍增益 5%，真机 65.8% vs 单模型 57.5%。

4.7 混合与层级（Hybrid & Hierarchical）

  • HybridVLA：协同训练自回归 + 扩散两种生成策略，兼顾接口与鲁棒性。
  • 层级 token 综合：上层语言/代码规划 + 中层 affordance/轨迹 + 底层 raw action；未来 VLA 转向"战略 token 综合"而非单一类型。
  • 双系统（System 1/2）：GR00T N1、CogACT、CoT-VLA 等把高层推理与低频动作生成解耦。

4.8 其他表示

  • Code-as-Policy / ViLa：用代码表达动作逻辑。
  • Goal State tokens：目标图/视频作终态（hind-sight relabeling 数据可扩展，但高质量一致目标生成难）。
  • Latent tokens：FSQ / NSVQ / VQ-VAE 构造（视觉/动作/目标基），可从无动作视频扩展，但粒度与可解释性是挑战。
  • Reasoning tokens（ECoT 等）：CoT 中间推理提升复杂任务泛化，代价是延迟与固定推理模式依赖。

5.3 时间组织：动作分块（Action Chunking）

  • 机制：一次前向预测未来 $H$ 步（8–50），重叠执行 + temporal ensemble；把控制频率从"每步一次推理"解耦。
  • 收益：① 摊销延迟（复杂度从 $O(K)$ 降到 $O(1)$）；② 平滑稳定（避免单步误差累积导致的抖动/stall）。
  • 代价：反应变慢（执行块期间不看新画面），对需实时反馈的动态任务不够灵活。
  • 几乎所有现代 VLA（无论 AR 还是 flow）都用某种 chunking；流匹配天然一次生成整段轨迹，与 chunking 契合度最高。

诚实结论（综合多篇对比）：tokenizer 与架构几乎总被共变，benchmark 任务构成决定赢家，目前缺乏"固定数据/主干/评测只扫动作表示"的跨实验室受控研究。可防御的总结是——*词汇表构建是一阶变量；离散性是好接口 + 可计算精度代价；任务物理决定代价是否可接受。* 两阵营正趋于融合而非对立（FAST 喂给 flow VLA 的训练管线；OpenVLA 离散头与扩散头同台）。

7. 前沿方向

  1. 层级 + 战略 token 综合：语言/代码（上层）→ affordance/轨迹（中层）→ raw action（底层）；多 token 类型协同。
  2. 预训练动作 tokenizer：FAST+/通用 VQ 分词器成为可复用资产，把"动作表示"从每项目重训中解放。
  3. 从模仿学习走向 RL：用 trial-and-error 获得更鲁棒/灵巧行为。
  4. VLA Agent 化：引入记忆、探索、规划、反思（memory / exploration / planning / reflection）。
  5. 视频世界模型：GR-2 / PAD / VPP 类，用大规模视频预训练学物理先验再迁移到策略。
  6. 能量/一致性引导：EBT / EqC / TeV / EnsembleVLA 把生成式策略统一到能量 landscape，实现自省、重试、分布级集成。
  7. 跨本体统一动作空间：RDT 的物理可解释统一空间、UniVLA 统一动作空间 tokenizer。
