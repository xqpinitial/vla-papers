项内容
一句话机器人的"心智"不必住在单个策略里——图结构 agentic 框架让感知/推理/预测/执行/验证/记忆各司其职：Main Agent 持任务态，角色化 Sub Agent 在隔离上下文里产出结构化证据，统一技能库把 VLA/WAM/验证器当可调用的技能——零微调打穿多个公开基准 + 真机
冻结全部异构后端（VLA、WAM、仿真模型等皆作为技能被调用）
演化无参数更新；系统级策略在闭环交互中"涌现"
命名EMERGE = 系统级智能从多组件协同中涌现

① 动机：单模型装不下长程任务

  • 单一端到端模型面对长程任务时，低级感知的频繁处理、高层规划的上下文思考、细粒度动作输出互相打架，导致逻辑混乱或误差级联崩塌。
  • 引 Annie Murphy Paul《延展的意识》："在头脑之外思考，意味着巧妙地借助头脑之外的实体。"——智能通过异构器官分工实现：眼睛感知、双手执行、大脑想象。

② 架构：图结构 + 角色化 Sub Agent + 统一技能库

组件职责
Main Agent在活跃上下文窗口内保持任务级状态：计划状态、恢复状态、相关记忆、近期证据、技能签名
Sub Agents（角色隔离上下文）感知 / 执行监控 / 验证 / 记忆固化——各自隔离上下文，只返回结构化、任务相关的证据（控制 Main Agent 的信息负载）
Unified Skill Library三类功能技能：Operational（VLA、运动原语…策略库）、Imagination（WM 预测 rollout、模型仿真）、Evaluation（评估进度/完成度、目标判据、失败分析）
Branch Stack 恢复局部化纠错：判据校验 → 文本失败诊断 → 从栈中回退重规划
token-aware 外部记忆保留任务相关状态，防上下文爆炸

③ 机制：闭环交互 = 系统级策略

任务指令 → Main Agent 层级任务规划（生成 Subgoal 1..n）
  → 委派：Operational Skill 执行 / Imagination Skill 预演 / Evaluation Skill 判据检查
  ← Sub Agents 返回结构化证据 → Main Agent 更新状态
  → 失败：判据驱动的验证 + 文本诊断 + Branch Stack 局部恢复（不全局重来）
  → 终止 / 重规划
  • 关键设计：Role-specific contexts——每个 Sub Agent 只暴露决策相关证据，Main Agent 不被原始观测淹没（与 HumanCLAW"紧凑文本历史最优"发现一致）。

④ 数据与结果

  • 零额外微调：LIBERO 系列、RoboDojo 等多个公开基准 + 真机实验，"outstanding performance"（论文口径）；
  • 卖点是系统级范式：模型即技能、图结构编排、异步并发协作。

⑤ 例子

叠放任务中：Verification Sub-Agent 用判据"红块完全位于蓝垫内且无倾斜"检查执行证据；不满足时诊断文本指出"释放过早"，Branch Stack 回退到"重新抓取"子目标而不是重跑整个任务；Imagination Skill 先用 WAM 预演"从左侧接近"的后果，预演失败则直接换策略，省一次真实执行。

⑥ 局限

  • 系统复杂度高：Main/Sub 多 agent + 三类技能的编排与通信开销；
  • "涌现"为系统级叙述，组件各自能力上限仍在；
  • 基准数字以论文表格为准（二手读报未给出统一均值，引用时需回查原文表）。

⑦ 簇内定位

  • 与 RoboHarness：都做异构编排——EMERGE 胜在角色隔离上下文 + 图结构信息流，RoboHarness 胜在交接分布匹配（Memory Bridge）；
  • 与 HarnessPAI：同样把模型当技能调用，EMERGE 加了 Imagination/Evaluation 两类"认知技能"与多 agent 分工；
  • 与 Orchestra：都在解决"长程谁记账"——EMERGE 用 Main Agent 活跃上下文 + 外部记忆，Orchestra 用共享执行上下文 + 独立进度评估器；
  • 名字即立场：具身智能系统的时代命题是"系统"，不是"模型"。
