2. 五条光谱轴（快速归类与选型的坐标系）

轴 1 · 动作来源：纯代码 ←→ 混合 ←→ 冻结 VLA 为主

  • 纯代码：RAX / ASPIRE / CaP-X / RATs（接触-rich 靠统一 API + 后端控制器；RAX 证明 0.1mm 插孔也行）
  • 混合：HarnessPAI（语义难阶段 grasp/place 交给冻结 VLA，其余代码）——继承 Harness VLA 的分工但把技能库放开
  • VLA 为主：Zetta（VLA 出动作，代码只监控与恢复）
  • 启示："纯代码做不了精细接触"这一 2025 共识正在被 RAX/ASPIRE 的 2026 结果动摇；但 RAX 依赖极重的后端控制器栈。

轴 2 · 演化对象：技能库 ←→ 代码库/程序 ←→ harness 本体

  • RATs/ASPIRE：技能为中心（函数 / 条件-动作对）
  • RAX/HarnessPAI：程序为中心（完整可执行程序 + 引用式技能；HarnessPAI 的四级节点中心存储最精细）
  • Zetta：harness 本体为中心（critic/恢复剧本/工具集本身被演化）

轴 3 · 学习时机：play 期 → 任务期 → 跨 rollout → 反哺训练

  • RATs 在任务到来前（无外部奖励，Goldilocks 内在动机）
  • RAX/ASPIRE 在任务期（探索预算 = 性能）
  • HarnessPAI/Zetta 跨 rollout（每个任务一个 success contract）
  • HarnessPAI 独有第五阶段：收敛程序当免费专家数据源（π0.5 34.9→73.7；DreamZero 5.1→26.5）——"外挂"与"内化"两条路线在此握手。

轴 4 · 谁动权重：只有两处——CaP-RL（GRPO 训练 agent 底座，Qwen-7B 20%→72% 级别）与 HarnessPAI 的下游 SFT。其余全部"模型冻结、能力长在工作区"。

推论：换更强底座模型 = 免费升级（ASPIRE 实测 Opus 4.6→5.5 直接把 LIBERO-Pro 打到 99%；RAX 同款结论"模型参数冻结、机器人能力随探索增长"）。

轴 5 · 质量门控哲学（决定技能库会不会"腐烂"）

  • 结果门控：RAX（无人值守成功才合并）
  • 过程门控：ASPIRE（verifier 独立复现）、HarnessPAI（里程碑前缀奖励 + 写/诊分离防自评分）
  • 统计门控：RATs（可靠性追踪三态）、Zetta（EOD 聚类 + held-out 回归）
  • 共同点：没有一篇信任 LLM 的自我报告，全部引入了独立于"写代码那个模型"的验证信号。

4. 成本与工程量

  • token/钱：ASPIRE 最贵（10 任务 API 成本 $40–600；真机一条失败轨迹 334M tokens）；RATs 附录有 token 成本分析，推理开销被列为局限；RAX 用"编译成程序"对冲——空气炸锅任务 agent 逐步决策 72.3min/262k tokens → 编译后无人值守 18 秒（241×），且效率随探索持续下降（123min→4min）。
  • infra：RAX 并行化 4 agents×4 envs（4.9h 得 92.2 vs 单 agent 13.7h 得 63.3）；Zetta 专门造了 Z-Infra（VLM/动作专家分进程 + CUDA IPC + W8A8/W4A16/W4A8 分模块量化）来喂自进化的 rollout 吞吐。
  • 人：RAX 真机每 episode 耗操作员时间；ASPIRE 需要隔离主机跑生成的代码（无安全沙箱）。

5. 选型速记

  • 有昂贵 VLA/WAM 想零微调提鲁棒 → Zetta（VLA 为主）或 HarnessPAI（混合）；想要"外挂经验反哺训练数据" → HarnessPAI。
  • 桌面/灵巧/长程操作、能接重控制器栈、追求 SOTA → RAX（探索预算换性能，scaling 曲线最完整）。
  • 想要可复用、可迁移、可审计的技能资产 → ASPIRE（失败签名→修复最系统）或 RATs（即插即用到别的 CaP agent）。
  • 要做研究/评测量化 → CaP-X 平台（其他五篇的公共地基）。
  • 任务还没来、想先攒能力 → RATs 的 play 范式。
